# Segar Drink 🥤

Website penjualan minuman segar dengan banyak menu + gambar.

## Menu yang tersedia
- **Kopi**: Es Kopi Susu Gula Aren, Cappuccino, Americano
- **Jus**: Jus Alpukat, Jus Mangga, Jus Stroberi
- **Susu & Shake**: Chocolate Milkshake, Vanilla Milkshake, Boba Brown Sugar
- **Teh & Lainnya**: Thai Tea, Es Teh Manis Jumbo, Matcha Latte

## Fitur
- Filter kategori (Semua / Kopi / Jus / Susu / Teh)
- Gambar produk dari Unsplash
- Tombol pesan langsung ke WhatsApp
- Tombol floating WhatsApp
- Responsive (HP & laptop)
- Banner promo

## Cara Upload ke GitHub Pages

1. Buat repository baru (Public) di GitHub
2. Upload file `index.html` dan `README.md` ini (langsung di root)
3. Masuk ke **Settings → Pages**
4. Source: **Deploy from a branch** → Branch **main** → Folder **/ (root)**
5. Klik **Save**
6. Tunggu 1-2 menit, buka:
   ```
   https://username-kamu.github.io/nama-repository/
   ```
